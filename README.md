# DSA Journey Repository

This repository is my DSA journey.

## Goals

- Build a strong foundation in Java
- Practice Data Structures and Algorithms regularly
- Improve problem-solving and coding confidence
- Learn Object-Oriented Programming by writing code
- Keep growing through system design practice

## Content

- Core Java practice
- DSA topics such as recursion, searching, sorting, strings, and backtracking
- OOP concepts and examples
- Pattern programs and small problem-solving exercises
- System design learning and implementation practice

## My Preparation

- Read concepts, then code them by hand
- Revisit older solutions and improve them
- Practice consistently instead of studying in one stretch
- Add new examples as I learn more

I will keep adding more code, more ideas, and more practice as I grow.
